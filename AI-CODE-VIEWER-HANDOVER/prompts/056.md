## Latest accepted rules

The top control deck must be compact and sticky while the title and summary can scroll. Category buttons remain brightly filled in category colors even when unselected, with an outline highlighting the active category. Selecting only a hierarchy recolors existing code rows in place, preserving scroll and row heights. The Full file button shows the cumulative source through the currently selected commit. The **All commits** control clears a range and restores the cumulative file at the last indexed commit. Display the short STM identifier and actual filename as separate aligned chips, but retain the original complete STM ID in the data and accessible row metadata. No sky-blue boundary chips, fabricated source rows, accidental extra green chips inside selected scopes, or unconditional green dividers.
