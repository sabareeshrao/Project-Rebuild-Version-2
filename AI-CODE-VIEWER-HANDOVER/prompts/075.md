# Prompt 075 — Screenshot: Restored Original Viewer Appears as Unstyled HTML

## User evidence

User supplied a Chrome mobile screenshot of the deployed `nanogpt-original-history/` page showing a white background, default browser typography/buttons and filename/STM/source code stacked without layout. The JS-driven source history itself loaded: 159 commits and 3,533 source rows were visible in the page text. No additional typed text accompanied the screenshot.

## Root cause

The prior UI restoration copied the original modular HTML stylesheet reference unchanged:

```html
<link rel="stylesheet" href="./assets/viewer.css">
```

But the standalone `nanogpt-original-history/` viewer had its CSS at `assets/style.css`, not `assets/viewer.css`. The referenced path returned 404, causing the browser to display HTML without CSS. The actual source diff/history data and JS logic were unaffected.

## Fix committed

Changed **only one path in** [`nanogpt-original-history/index.html`](../../nanogpt-original-history/index.html):

```html
<link rel="stylesheet" href="./assets/style.css">
```

Commit [`d6414dee`](https://github.com/sabareeshrao/Project-Rebuild-Version-2/commit/d6414deef32f63c4b3f1c1e8becb1e48dfaaea4f). Source styling remains the unchanged actual black-theme original modular CSS, including green category chips, syntax colors, compact sticky header and original filename → STM → code layout. All-commits default and 159 genuine Git commits remain untouched.

## QA / limits

10/10 repository contract checks verified correct CSS URL, existing CSS file contents, dark-theme properties, JS history/syntax import paths, default `All commits` mode and deleted-code strikethrough. GitHub Pages HTTP contents **could not be independently fetched using the browser tool**, so live deployment propagation and actual mobile browser CSS rendering were not verified. The user's screenshot establishes that the HTML/JS page had been served in their browser before this fix.

No other files in the viewer were changed for this correction. The old modular viewer, prototype and 235 synthetic educational commits are unchanged.
