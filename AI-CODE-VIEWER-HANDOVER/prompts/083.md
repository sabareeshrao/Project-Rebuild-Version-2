## Accepted palette and behavior

| STM category | Approved exact color | Membership |
|---|---|---|
| Project | Teal `#0D9488` | Every verified source row in this nanoGPT project |
| Global / Module-level | Slate `#475569` | Python source outside class/function scopes, including top-level control-flow |
| Imports | Cyan `#0E7490` | Original Python import statements, including continued physical lines |
| Assignments | Gold `#A16207` | Python simple, annotated, augmented, and multiline assignments |
| Expressions / Calls | Ruby `#BE123C` | Standalone Python expressions and calls, including multiline continuations |

Only the STM chip is painted. The filename chip remains independently controlled by File; recognized Python documentation is painted pink with Comments ON no matter which primary category is selected. Unmatched members in a focused category stay neutral. Project and Lines color all rows, including non-Python files. Source text, event ordering, permanent IDs and deletions remain untouched. No additional chips/rows/group labels are inserted.

Existing primary modes (Module, Directory, Class, Method, Code Block, Nested Block, Lines), the original dark CSS layout, compact sticky toolbar, green code-column sibling dividers, Full File, Added only, Selected, All commits, numeric/range jumps, file filters and localStorage persistence retain their behavior. The new controls use the existing one-line horizontally swipeable category bar.

### Important limitation

This browser-side category scanner is deliberately not a full Python AST parser. Complex or ambiguous syntax may remain neutral, rather than being assigned a false statement type. Distinguish a structural **scope** (e.g. Method or Global) from a statement **type** (e.g. Assignment or Import); a line may belong to both, but only the selected primary color is displayed. No synthetic source lines or Git commits are introduced.

The public Android/GitHub Pages deployment was not independently visually verified in this work.
