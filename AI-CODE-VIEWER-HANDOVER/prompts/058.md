# Prompt 058 — Prompt records must not be confused with UI-only changes

## Exact user prompt

## Interpretation and corrective scope

This message flags a concern about **UI-change records versus a complete record of the project conversation**. The pre-existing 57 numbered records contain several non-UI topics (source-ID hierarchy, source Git-history counting, batching, modular architecture, source audits and handover questions), but they are not a full, lossless ChatGPT message export. They also rely on assistant-response **summaries**, not original verbatim replies.

The handover must make this distinction transparent. Maintain a chronological ALL-PROMPTS index and a separate UI-focused view, so a replication AI can learn from both coding/project-workflow decisions and visual feedback without confusing one for the other. Do not silently delete history or invent previously unavailable full assistant responses.

## Fidelity rule

A documentation record must distinguish: (a) exact user prompt text when accessible, (b) assistant response summary versus verbatim output, (c) executable implementation and commit links when present, (d) evidence of QA tests, (e) uncertainty or inaccessible screenshots/older replies. Every conversational prompt may be recorded; not all prompts imply code changes or should generate implementation commits.
