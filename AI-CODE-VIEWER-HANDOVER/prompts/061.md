F. Commit viewing controls

Preserve:

- Full file: Cumulative historical source through the selected commit.
- Added only: Lines introduced in that commit.

- "5" → Only additions introduced at commit 5.
- "5-10" → Only additions introduced across commits 5 through 10.
- All commits → Currently all 15 indexed commits, eventually all 235.
